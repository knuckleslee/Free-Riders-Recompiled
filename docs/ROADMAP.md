# Roadmap

尚未開始的計畫。完成或放棄時移出這份清單，並寫進對應的說明文件。

## 動作輸入

- **暫停手勢（Pause Gesture）與 Kinect 調整視窗**：已實作，等待實機測試
  （[Kinect 與 Kinect v2](kinect-sensor.md)、[攝影機體感](camera-input.md)）。
- **自動仰角**：依站位自動調整 Kinect 馬達仰角。延後。
- **可關閉進入比賽前的校正**：進入比賽（以及從手把或失去追蹤回到體感）時，目前要先站好
  約一秒做站姿校正。加一個設定讓玩家關掉這一步，改用上一次的校正結果；第一次遊玩、
  換玩家或站位改變太多時仍需要校正。
  - 待確認：哪些校正是遊戲原本的流程、哪些是本專案加的（攝影機與 Kinect 的站姿、
    地板高度、仰角修正），各自能否沿用舊值。
  - 待確認：沿用舊值時，站位偏了是否會造成誤轉向或誤蹲，需要什麼條件自動退回重新校正。

## 畫面

- **寬螢幕對應**：在 21:9 等比 16:9 更寬的螢幕上，用滿畫面寬度，而不是左右加黑邊。
  - 3D 畫面加寬視野（水平 FOV 依比例放大，垂直不變）。
  - HUD 與選單維持 16:9 的配置並置中，或把貼邊的元素移到新的邊緣；觸控圈與暫停手勢的
    進度環跟著移動。
  - 待確認：遊戲的投影矩陣與剔除範圍在哪裡設定，加寬後邊緣是否有物件沒畫出來
    （[Issue 31 調查](issue-31-investigation.md) 目前只比較過加黑邊的輸出）。
  - 分割畫面（兩位玩家）另外處理。
